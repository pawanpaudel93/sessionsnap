Save your cmux workspaces. Bring them back resumed.

sessionsnap takes named, versioned snapshots of your cmux workspaces and the coding-agent sessions in their tabs. Later it reopens only what is missing, with each agent resumed in its own folder with the flags it was started with.

Install from Terminal

curl -fsSL https://sessionsnap.pawanpaudel.com.np/install.sh | sh curl -fsSL https://sessionsnap.
pawanpaudel.com.np/install.sh | sh

Free and open source (MIT). macOS or Linux, with cmux 0.64 or newer. One binary in ~/.local/bin; nothing runs in the background. Update with sessionsnap update; remove with sessionsnap uninstall.

Save, edit, restore

Every snapshot is one you ask for. Nothing watches your terminal.

  1. Save

    Capture every open workspace, its tabs, and the agent session in each tab with the flags it was started with. Saving to an existing name adds a version.

    save worksave work -w Cascadia

  2. Edit

    Rename, reorder and remove workspaces, move tabs between them, or add an agent session by its ID. Each edit is a new version you can diff.

    tabwshistorydiff

  3. Restore

    See the plan first, then reopen only what is missing. Agent tabs come back resumed; plain tabs reopen in their folder.

    restore work --planrestore work

What it does

A single Rust binary with a CLI, a web UI in the cmux Dock, and cmux palette commands.

Snapshots with history
Every save to an existing name is a new version. List, diff and restore any version, and prune old ones.
Agent-aware restore
Agent tabs come back with claude --resume <id>, codex resume <id> and so on, keeping their original flags.
Only what is missing
A restore is a plan you can preview with --plan. Workspaces and tabs that are already open are left alone.
Find lost sessions
recent lists agent sessions from the last day that are not open in cmux, and can reopen them.
Scriptable
Every command takes --json and --yes, with stable exit codes. A Claude Code skill teaches agents to use it.
Careful with your shell
Every word of a restore command is shell-quoted and session IDs are checked. Credential-like flags and environment variables are never saved.

Full support also reads the agent's session history: titles, sessions, recent, and checking that a saved session still exists. cmux records which agent runs in a tab; for agents other than Claude Code it does so only after cmux hooks setup <agent>.

A web UI in the cmux Dock

sessionsnap ui serves a small page on 127.0.0.1 and shows it in the cmux Dock, or run “sessionsnap: Open UI” from the cmux palette. It stops after 30 minutes without use.

Snapshots and history

Save what is open, update a snapshot from what is open, compare two versions, or restore an older one.

Edit by dragging

Rename, reorder and remove workspaces, drag tabs between them, and add agent sessions or shell tabs. Edits are previewed and saved as one version.

Restore and recent

Tick the workspaces and tabs you want, see what would open, then restore. Recent lists agent sessions that are not open in cmux.
